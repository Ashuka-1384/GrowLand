GrowLand — Vercel Deployment Checklist

1. Push this exact project to the GitHub repository connected to Vercel.
2. In Vercel, connect a PRIVATE Vercel Blob store to the project.
3. Confirm Production has BLOB_READ_WRITE_TOKEN.
4. Set Production SESSION_SECRET to a long random value.
5. Optional: set MASTER_ADMIN_PHONE if the master admin is not +989333167279.
6. Redeploy the newest commit with “Redeploy” and do not use an older deployment.
7. Confirm the build starts with npm run build and ends with a successful deployment.
8. If an old CSS warning appears again, verify the Vercel deployment commit contains app/globals.css from this package and BUILD_VERSION.txt = 2026-09-27-fix-04.

Expected result:
- No Autoprefixer “end value has mixed support” warning.
- TypeScript check completes successfully.
- Next.js production build completes successfully.
- First production request can initialize the Blob JSON seed automatically.
